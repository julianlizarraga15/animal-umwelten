# Project status

Handoff updated: 2026-11-21 (readable garden opening)

## Current application

Umwelt Explorer opens on an afternoon patio with one Rudbeckia and one pale
silk web. The Spanish heading and dek name the two lessons: flower contrast
and web vibration. The patio hides specimen captions and lesson controls;
the relevant caption and controls appear only after arrival. `CameraState`
remains the sole location owner, with one exhaustive `placeCopy` mapping for
copy and visibility.

Four sparse climbing vines replace the repeated wall leaf grid, leaving the
door and window readable. Six leaves remain beside the path, and each small
path pot now has a stem and two leaves. One low leaf frames each foreground
corner. The web is full scale with brighter pale silk, and the bee is larger
on the opening flower. The Rudbeckia geometry, upper-face-only UV guide, four
web sectors, and spider signal behavior are unchanged. Renderings remain
explanatory and do not claim literal animal subjective experience.

## Validation

On 2026-11-21, `npm run typecheck`, `npm run build`, and `npm run
check:browser` passed on Windows. The suite covered 1440×1000 and 390×844,
flower UV switching, reverse-petal inspection, web sectors, touch, reduced
motion, and WebGL recovery. It found no viewport occluders. The SwiftShader
patio frame reports 1,115,632 triangles, down from the prior documented
approximately 1.53M. Captures and metadata are in `test-results/patio/`.
The build retains its existing chunk-size warning. No physical device or
deployment was tested.
