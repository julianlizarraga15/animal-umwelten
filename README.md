# Umwelt Explorer

An exploratory interactive project inspired by Ed Yong's *An Immense World*.
Explore how animals detect different signals in the same environment.
Representations explain sensory differences; they cannot reproduce an animal's
subjective experience.

The initial candidate is a small garden with camera movement and a switch
between a human reference view and an illustrative bee perception view.
Scope and technology remain provisional. There is no application yet.
