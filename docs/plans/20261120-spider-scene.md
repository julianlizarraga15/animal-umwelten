# Make the spider scene readable

## Question

Can the spider lesson look like a small garden web with a legible spider, rather than a bright circular diagram dominating the approach view?

## Smallest experiment

Reshape the web into a restrained radial-and-spiral structure, improve the spider silhouette with a distinct cephalothorax, abdomen, and articulated legs, and simplify the nearby supports so they read as stems. Preserve the four interactive sectors and signal behavior.

## Acceptance

- The spider reads as an eight-legged animal at the web view.
- Silk and supports feel integrated with the garden and remain legible.
- Sector hit targets, signals, and lesson wording remain accurate.

## Validation

Run typecheck, build, and browser checks; inspect patio and web captures.

## Unresolved

Whether the revised web scale reads clearly on a phone.
