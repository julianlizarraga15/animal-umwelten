# A readable garden opening

## Question

Can a first-time visitor name the patio and its two lessons without controls
covering the garden?

## This experiment

Derive visible copy and lesson controls from `CameraState`, then replace the
wall leaf grid with four sparse vines. Keep the existing flower, web lesson,
camera poses, and bounded scientific claims.

## Acceptance

The opening names flower contrast and web vibration, leaves the sampled canvas
points clear, and shows no specimen caption or lesson panel. The door, window,
pale web silk, and bee remain readable at desktop and mobile sizes.

## Validation

Run `npm run typecheck`, then `npm run build`, then `npm run check:browser`.
Inspect the generated patio, flower, and web captures.
