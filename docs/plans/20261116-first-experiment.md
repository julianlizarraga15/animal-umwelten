# First perception experiment

Status: draft. Implementation has not started.

## Question

Can switching between two representations of the same small scene help someone
understand a documented difference in sensory detection?

## Smallest candidate

One garden-like scene, camera movement, and a human/bee view switch. Use basic
geometry before custom models. Explain what each representation encodes.

## Before implementation

- Briefly compare Three.js with TypeScript, React Three Fiber, and engine options.
- Choose one documented sensory difference and record primary scientific sources.
- State which visible effects are explanatory choices and which claims they support.
- Select the smallest stack and file structure supported by those needs.

## Acceptance and validation

- The scene loads locally and camera controls work.
- Switching views changes the intended signal in the same environment.
- The explanation identifies the sensory difference and the representation's limits.
- Inspect the running experience in a browser and run the selected tooling's checks.

## Open choices

Technology, exact signal, visual encoding, controls, and final scope remain open.
